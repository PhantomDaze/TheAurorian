## 执行方式

- `rnServer` 的 workingDirectory 实际是 `run/server`（build.gradle 覆盖），不是 `run/`。
- 途径 A（stdin 喂指令）失败：ForgeGradle JavaExec 不透传 stdin，`list`/`stop` 无效果，EXIT=124。
- 途径 B（世界数据包 `minecraft:load` 函数）成功：函数命令输出用 `say` 写入服务端控制台。
  - 注意：1.19.2 函数内无法解析 `save-all` / `stop`（EXIT/日志报 Unknown command），故用 timeout 结束。
  - 注意：1.19.2 NBT 路径不支持 `ArmorItems[3]{id:"..."}`（解析错误）；改用整表 `nbt={ArmorItems:[...]}` 匹配 + 数值型 `Count` 断言。
  - 注意：`Mob` 序列化空装备槽为 `{}`，不是 `{id:"minecraft:air"}`。

## 缺陷记录（未改代码）

1. `src/main/resources/data/theaurorian/loot_tables/entities/aurorian_sheep.json`
   16 处 `"type_specific":{"type":"minecraft:sheep",...}`。1.19.2 的 `EntitySubPredicate.Types` 无 `sheep`
   （仅 lightning/fishing_hook/player/slime/cat/frog），导致整张表解析失败：
   `Couldn't parse loot table theaurorian:entities/aurorian_sheep` + `Unknown sub-predicate type: minecraft:sheep`。
   1.20.1 参考树已移除该写法。
2. 结构 NBT 中 43 个 `theaurorian:silentwood_chest` 调色板条目的 `waterlogged` 为 ByteTag（`0b`），
   1.19.2 期望字符串 `"true"/"false"`，放置时告警：
   `Unable to read property: waterlogged with value: ...`。功能上默认 false，影响小。
   涉及 moontemplev2_*、darkstone_*、runestone/bottom 等。
