# 隔离原版生物模型

- 状态：已完成（源码静态验证和模型相关 Java 直接编译通过；完整 Gradle/客户端验证受依赖与环境限制）
- 日期：2026-08-31

## 目标

将实体渲染中直接依赖 vanilla `ModelLayers` 与具体生物模型类的部分迁移到 `theaurorian` 自有 `ModelLayerLocation` 和 Java `LayerDefinition`，保持现有动画、护甲、覆盖层、纹理和缩放行为，避免客户端对原版实体模型/层的修改连带影响 mod 生物。

## 已完成

- 增加自有的人形、四足、骨骼、蜘蛛和史莱姆外层模型实现。
- Hollow、Undead Knight、Moon Queen、Moon Acolyte、Spirit、Disturbed Hollow、Dungeon Keeper、Dungeon Spider 全部改用 mod-owned layer。
- Dungeon Keeper 的主体、护甲和服装覆盖层分离为 `main`、`inner_armor`、`outer_armor`、`outer`。
- Pig、Rabbit、Sheep 主体/羊毛模型不再继承 vanilla 具体模型类或调用其静态 layer 工厂。
- Sheep 主体和羊毛材质改为 `theaurorian:textures/entity/aurorian_sheep*.png`，并复制原版纹理作为初始资源。
- Dungeon Slime 外层改为自有模型。
- EntityClientRegistry 注册所有新增层；EntityRegistry 保持 server-safe。
- 增加静态 JUnit 检查，阻止实体目录重新引入 vanilla 生物模型层/类和 vanilla sheep 纹理路径。
