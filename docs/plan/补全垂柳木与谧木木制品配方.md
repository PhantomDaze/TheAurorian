## 已确认的事实（2026-08-14）

- **weeping_willow（垂柳木）**：leaves / log / planks / sapling / stairs

**本项目未注册**：silentwood_door、silentwood_trapdoor、weeping_willow_slab、weeping_willow_door、weeping_willow_trapdoor。
全项目（含 build 产物、libs、run/mods）均无 door/trapdoor 资源。

- `shaped/silentwood_slab.json`：6× 木板 → 6 台阶
- `shaped/silentwood_stairs.json`

**缺失**：`shapeless/weeping_willow_planks.json`（垂柳木 log → 木板）——方块已注册，配方缺失。

## 关键结论 / 分歧点

用户列出的 5 个方块（谧木门、谧木活板门、垂柳木台阶、垂柳木门、垂柳木活板门）在本项目中**均未注册**。
若直接添加指向未注册物品的配方，会导致数据包/配方解析失败。

唯一已注册且缺配方的：**weeping_willow_planks**。

→ 需要用户确认：是补全两种木头的完整方块组（注册方块 + 模型/贴图/loot/语言/配方），
还是仅补已存在方块的配方。
